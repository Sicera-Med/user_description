# ML-часть: тактика по протоколу лучевого исследования

По протоколу (описание + заключение) LLM предлагает врачу варианты дальнейшей тактики
со ссылками на официальные документы. После решения врача пишет пациенту понятное объяснение.

Исследования: КТ ОГК, РГ/ФЛГ ОГК, маммография, КТ ГМ.
Модели — через HF Inference API (`huggingface_hub`).

## Как устроено

1. В промт идут: протокол, шаблон протокола из БФТ, записи справочника «находка → действие» для этого типа исследования.
2. Модель возвращает JSON: варианты (повторный приём / консультация / доп. исследование / экстренная госпитализация),
   в них пункты с кодами, причиной и `sources` — id записей справочника.
3. Код проверяет формат и ссылки: источник (документ, страницы) показывается, только если в записи есть это действие.
   Иначе пункт помечается как предложение модели.
4. Если записей по словам протокола не хватило, модель может попросить весь справочник (`need_full_guidelines`) — второй запрос.

## Файлы

| Файл | Что делает |
|---|---|
| `analysis.py` | промт, коды, сборка запроса, разбор и проверка ответа, подстановка источников |
| `guidelines.py` | справочник: отбор записей по словам протокола, текст для промта, проверка и ссылки |
| `bft_templates.py` | шаблоны протоколов из БФТ по типу исследования |
| `test_of_b2c.py` | сообщения пациенту: SMS и текст на сайте с решением врача |
| `test_of_models.py` | старый прогон тестов на моделях из `.env` |
| `guidelines/*.json` | справочник по типам исследований, `sources.json` — список документов |
| `bft_templates.json` | шаблоны БФТ |
| `sources/` | PDF документов (КР Минздрава, методички НПКЦ ДиТ, приказ 404н) |
| `tests/` | тестовые случаи и прогоны (ниже) |

## Тесты

- `tests/cases.md` — 10 протоколов, у части есть ожидания из справочника (их должен проверить врач).
- `tests/test_models.py` — 5 моделей 4–8B + GPT на 10 случаях.
- `tests/test_guidelines.py` — GPT на 5 случаях, со справочником и без.

Отчёт каждого прогона — новый файл в `tests/results/`.

## Запуск

```bash
python -m venv venv && venv/bin/pip install huggingface_hub python-dotenv
```

В `.env`:
```
HF_TOKEN=...
MODEL=Qwen/Qwen3-4B-Instruct-2507   # для test_of_models.py и test_of_b2c.py, можно несколько через запятую
GPT_MODEL=openai/gpt-oss-20b        # необязательно
```

```bash
venv/bin/python tests/test_models.py
venv/bin/python tests/test_guidelines.py
venv/bin/python test_of_b2c.py
```

## Заметки

- Нужны эталоны врачебных решений и проверка справочника и ожиданий врачом.
